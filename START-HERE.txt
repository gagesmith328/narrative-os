NARRATIVEOS — START HERE

1. Stop the old development server with Ctrl+C.
2. Open this folder on your computer:
   C:\Users\smitt\Desktop\narrative-os
3. Copy everything from this downloaded project into that folder.
4. Choose Replace when Windows asks about existing files.
5. Open a terminal in the narrative-os folder.
6. Run:

   npm install
   npm run dev

7. Open http://localhost:3000

No API key is required for the current DEX Screener feed.

Main files:
- components/NarrativeApp.tsx = full dashboard interface
- app/api/narratives/route.ts = live data API
- lib/narrative-engine.ts = grouping and scoring engine
- app/globals.css = full design and responsive layout
